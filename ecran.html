    Installation : ma clé fixe

    Définissez une seule clé privée de 32 caractères minimum dans le champ de connexion. Enregistrez-la une fois dans le credential Header Auth n8n, sous la forme Bearer suivi de cette clé. Si votre accès fonctionne déjà, gardez votre clé actuelle.

    Conservez ce code dans votre gestionnaire de mots de passe. Il n’est pas intégré aux fichiers publics du site.
