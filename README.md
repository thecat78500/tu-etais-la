# Tu Étais Là

Démonstration d’un jeu d’enquête fantastique pour 4 à 10 joueurs, conçue pour iPad.

L’accueil index.html reste une démonstration autonome avec des codes visibles. L’écran ecran.html se connecte séparément aux parties n8n, après association privée par la commande Telegram /ipad. Le webhook de lecture doit être installé et activé sur l’instance n8n avant utilisation. Dix affaires sont présentées avec leurs images et leurs introductions ; leurs cinq familles d’énigmes sont générées et validées côté n8n. Les rôles, camps et indices privés restent sur Telegram.

L’administration des images conserve ses imports dans le navigateur de cet appareil. Le Studio des voix, ses scripts privés, le service serveur et les documents de conception ne sont pas inclus dans cette publication.

Publication : Settings → Pages → Deploy from a branch → main → / (root).
