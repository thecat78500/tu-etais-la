Les voix
de la maison.

Copiez un texte dans ElevenLabs, générez la voix puis téléchargez le MP3 avec le nom indiqué. Commencez par Sally avec Ingrid. Importez ensuite le fichier sous son script pour suivre votre avancement. Cette page ne génère pas de voix et ne consomme aucun crédit.

Réservé à la préparation : ces textes révèlent des messages privés et des fins. Les fichiers communs ne sont à enregistrer qu’une seule fois pour toutes les affaires.

Vos enregistrements

Les imports restent dans ce navigateur, sur cet appareil. Utilisez le panneau serveur ci-dessous pour transmettre une copie au serveur du bureau. Aucun envoi au bot ne se fait pendant cet import. Gardez vos originaux : effacer les données du navigateur efface aussi ces copies.

Le nom doit correspondre au script pour un import groupé. Pour un export ElevenLabs avec un nom différent, utilisez l’import du script concerné. Les formats sont conservés, sans conversion.
